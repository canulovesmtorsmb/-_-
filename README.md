# История литературы · Античность

Учебный сайт по истории древнегреческой и древнеримской литературы.
Статический HTML, никаких сборщиков, готов к деплою на GitHub Pages.

## Что внутри

### Контентные разделы
- **Главная** (`index.html`) — витрина всех разделов и инструментов
- **Греция:**
  - `greece/istoriya.html` — История Греции (от Микен до Рима)
  - `greece/mifologiya.html` — Греческая мифология
  - `greece/literatura.html` — Обзор древнегреческой литературы
  - `greece/gomer.html` — Гомер: Илиада и Одиссея
  - `greece/poeziya.html` — Лирика и эпиграмма
  - `greece/dramaturgia.html` — Трагедия и комедия
  - `greece/ritorika.html` — Античная риторика
- **Рим:**
  - `rome/istoriya.html` — История Рима
  - `rome/literatura.html` — Римская литература
  - `rome/eneida.html` — Вергилий: Энеида

### Тексты античных авторов (`texty/`)
- `texty/gomer.html` — Гомер: точка входа к «Илиаде» и «Одиссее»
- `texty/iliada/` — «Илиада», все 24 песни в переводе Гнедича (1829)
- `texty/odisseya/` — «Одиссея», все 24 песни в переводе Жуковского (1849)
- `texty/lirika.html` — фрагменты Сапфо и Архилоха в переводе Вересаева
- `texty/epigrammy.html` — греческая эпиграмма в переводе Блуменау
- `texty/katull.html` — Катулл в переводе Пиотровского

### Интерактивные инструменты (`tools/`)
- `tools/timeline.html` — таймлайн ~40 событий с фильтрами по периодам
- `tools/glossary.html` — словарь ~65 терминов с поиском
- `tools/flashcards.html` — флэш-карты (4 набора, ~80 карт)
- `tools/quiz.html` — 4 теста (50+ вопросов с объяснениями)

### Визуализации
13 крупных оригинальных SVG-иллюстраций встроены в контентные страницы:
карта античной Греции, генеалогия богов, иконки олимпийцев, схема гекзаметра,
карты странствий, план греческого театра, риторический треугольник,
композиция «Энеиды», карта расширения Рима и др.

## Деплой на GitHub Pages

### Вариант 1 — новый репозиторий

```bash
# Распакуй ZIP в пустую папку, зайди в неё.
cd antiquity-lit

git init
git add .
git commit -m "Initial commit"
git branch -M main
git remote add origin https://github.com/USERNAME/antiquity-lit.git
git push -u origin main
```

На GitHub.com:
1. Settings → Pages
2. Source: **Deploy from a branch**
3. Branch: **main**, folder: **/ (root)**
4. Save

Через 1-2 минуты сайт будет доступен на `https://USERNAME.github.io/antiquity-lit/`.

### Вариант 2 — кастомный домен

В Settings → Pages → Custom domain укажи свой домен.
В корень репозитория нужно положить файл `CNAME` с одной строкой — твой домен.
На стороне домена прописать CNAME-запись на `USERNAME.github.io`.

### Вариант 3 — обновление существующего репозитория

```bash
# Из папки с распакованным архивом
git add .
git commit -m "Update site"
git push
```

GitHub Pages пересоберёт сайт за 1-2 минуты.

## Локальная проверка

Самое простое — открыть `index.html` двойным кликом в браузере.

Если хочешь проверить через локальный сервер (некоторые браузеры ругаются
на `file://` для fetch):

```bash
# Python 3
python3 -m http.server 8000
# Открыть http://localhost:8000

# Или Node.js
npx serve .
```

## Дизайн

Концепция: «античная рукопись + современный интерактивный учебник».
Палитра — пергаментный фон (#F4ECD8), терракотовые (#B85042), охристые (#C4923A)
и лазуритовые (#2E4A6B) акценты. Шрифты подгружаются с Google Fonts:
Cormorant Garamond, EB Garamond, JetBrains Mono. Без интернета сайт работает,
но шрифты будут системные.

## Авторские права на тексты

Все переводы в разделе `texty/` находятся в общественном достоянии
по российскому законодательству (70 лет с года смерти переводчика):

- Н. И. Гнедич (ум. 1833) — «Илиада»
- В. А. Жуковский (ум. 1852) — «Одиссея»
- В. В. Вересаев (ум. 1945) — переводы лирики
- Л. В. Блуменау (ум. 1936) — греческая эпиграмма
- А. И. Пиотровский (ум. 1937) — Катулл

Содержательные страницы курса (`greece/`, `rome/`) — оригинальный учебный
текст, написанный на основе общеизвестных историко-литературных фактов.
